EnvTTS-Bench Examples

Each EnvTTS-Bench item is a pair of real recordings. The environment reference comes from the same acoustic environment but different speakers; the speaker reference comes from the same speaker under a different recording condition.

  • Environment Ref.: Speaker A recorded in acoustic condition A
  • Speaker Ref.: Speaker B recorded in acoustic condition B

Comparison: EnvTTS-DiT vs. Cascade

Both systems synthesize the same text from the same environment and speaker references drawn from EnvTTS-Bench. Cascade extracts the background from the environment reference with SAM-Audio, mixes it with the speaker reference at the estimated SNR, and uses the mixture as the prompt. EnvTTS-DiT (ours) conditions generation directly on the unseparated environment reference and a separate speaker reference.
